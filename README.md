# ตรวจใบกิจกรรม (Activity Check)

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/rachatasawasdikit-collab/activity-sheet-checker)
[![Live demo](https://img.shields.io/badge/ลองใช้-สาธิต-0e6b5b)](https://rachatasawasdikit-collab.github.io/activity-sheet-checker/)

ระบบตรวจใบกิจกรรมออนไลน์สำหรับครูและนักเรียน ใช้งานบนเบราว์เซอร์ ทำงานเป็นเซิร์ฟเวอร์เดียวกับฐานข้อมูล SQLite จึงใช้ได้หลายเครื่องในเครือข่ายเดียวกัน

## ลองใช้งานออนไลน์

| แบบ | ลิงก์ | หมายเหตุ |
| --- | --- | --- |
| **สาธิต** (ไม่ต้องติดตั้ง) | <https://rachatasawasdikit-collab.github.io/activity-sheet-checker/> | รันบน GitHub Pages ด้วย backend จำลอง (demo/demo-api.js) ข้อมูลเก็บใน localStorage ของแต่ละคน ไม่แชร์กัน ใช้บัญชีตัวอย่างด้านล่างได้เลย |
| **ตัวจริง** (Node + SQLite) | ปุ่ม *Open in GitHub Codespaces* ด้านบน | เปิด Codespace แล้วเซิร์ฟเวอร์สตาร์ทเองที่พอร์ต 3000 (public) — ใช้ข้อมูลจริงใน data/ ของ Codespace |

โหมดสาธิตสร้างใหม่ได้ด้วย `npm run build:demo` (คัดลอก `public/` → `docs/` แล้วแทรก `demo-api.js` + `bridge.js`)

### เชื่อมหน้า Pages เข้ากับเซิร์ฟเวอร์จริง

1. เปิดเซิร์ฟเวอร์ให้เข้าถึงจากอินเทอร์เน็ตได้ เช่น `cloudflared tunnel --url http://localhost:3000`
2. สตาร์ทเซิร์ฟเวอร์โดยอนุญาต origin ของ Pages:
   `CORS_ORIGINS=https://rachatasawasdikit-collab.github.io npm start`
3. เปิดหน้า Pages แล้วกด **เชื่อมเซิร์ฟเวอร์** มุมล่างซ้าย ใส่ URL ของเซิร์ฟเวอร์
   หรือเปิด `<pages-url>?api=https://xxxx.trycloudflare.com`

เมื่อเชื่อมแล้วหน้า Pages จะเลิกใช้ข้อมูลจำลอง แล้วเรียก API จริงด้วย Bearer token
(ไม่ใช้ cookie เพราะเบราว์เซอร์บล็อก third-party cookie ข้ามโดเมน) — ครูและนักเรียนคนละเครื่องจึงเห็นข้อมูลชุดเดียวกัน

## ฟีเจอร์

- **ห้องเรียน** — ครูสร้างห้องเรียนและได้รหัส 6 ตัวให้นักเรียนเข้าร่วม หรือครูจะสร้างบัญชีนักเรียนเองก็ได้
- **ใบกิจกรรม 2 รูปแบบ**
  - ตรวจแบบ **ผ่าน / ไม่ผ่าน** พร้อมความคิดเห็น
  - ตรวจแบบ **ให้คะแนนรายหัวข้อ** กำหนดคะแนนเต็มแต่ละหัวข้อและเกณฑ์ผ่าน ระบบคิดคะแนนรวมและตัดสินผลให้
- **การส่งงาน** — นักเรียนพิมพ์คำตอบและ/หรือแนบรูปใบกิจกรรมหรือ PDF (ไม่เกิน 15 MB)
- **หน้าตรวจของครู** — เห็นรายชื่อทั้งห้อง สถานะการส่ง คะแนน และบันทึกผลงานกระดาษได้แม้นักเรียนยังไม่ส่งออนไลน์
- **สรุปผลและส่งออก** — ภาพรวมความคืบหน้า คะแนนเฉลี่ย และส่งออกผลเป็น CSV เปิดใน Excel ได้ (รองรับภาษาไทย)
- **หลายผู้ใช้** — แยกสิทธิ์ครู/นักเรียน และแยกข้อมูลตามห้องเรียน
- **นักเรียนไม่ต้องสมัคร** — ครูอัปโหลดรายชื่อ (CSV/Excel) แล้วนักเรียนเข้าเรียนด้วยรหัสห้อง + เลือกชื่อตัวเอง
- **session แยกตามแท็บ** — เปิดหลายแท็บในเบราว์เซอร์เดียวเพื่อทดสอบเป็นครูและนักเรียนพร้อมกันได้ (ข้อมูลยังแชร์กันที่เซิร์ฟเวอร์)

## เริ่มใช้งาน

ต้องใช้ **Node.js 22.14 ขึ้นไป** (ใช้ `node:sqlite` ที่มีมาใน Node โดยไม่ต้องติดตั้งฐานข้อมูลเพิ่ม)

```bash
npm install
npm run seed     # ไม่บังคับ: สร้างข้อมูลตัวอย่าง
npm start
```

เปิด <http://localhost:3000>

### บัญชีตัวอย่าง (หลังรัน `npm run seed`)

| บทบาท | ชื่อผู้ใช้ | รหัสผ่าน |
| --- | --- | --- |
| ครู | `teacher` | `123456` |
| นักเรียน | `student01` – `student08` | `123456` |

รหัสห้องเรียนตัวอย่าง: `SCI501` (มีข้อมูล) และ `SCI502` (ห้องว่าง)

### ใช้หลายเครื่องในห้องเรียน

1. รันเซิร์ฟเวอร์บนเครื่องครู
2. ดู URL เครือข่ายที่โปรแกรมแสดงตอนเริ่ม เช่น `http://192.168.1.20:3000`
3. ให้นักเรียนเปิด URL นั้นใน Wi-Fi เดียวกัน (Windows อาจถาม permission ของ firewall ครั้งแรก)

## วิธีใช้งาน

### ครู

1. สมัครบัญชีประเภท **ครูผู้สอน**
2. สร้างห้องเรียน แล้วคัดลอกรหัสห้องเรียนให้นักเรียน
3. เพิ่มนักเรียนทีละคน หรือ **ลากไฟล์รายชื่อ** (CSV / TXT / Excel) เข้าหน้าต่างเพิ่มนักเรียน
4. สร้างใบกิจกรรม เลือกวิธีตรวจ กำหนดส่ง และหัวข้อให้คะแนน (ถ้าเลือกให้คะแนน)
5. เปิดใบกิจกรรม → กด **ตรวจงาน** ของนักเรียนแต่ละคน → บันทึกผล
6. กด **ส่งออก CSV** เพื่อเก็บผลทั้งห้อง

### นักเรียน

1. เปิดหน้าเว็บ → แท็บ **นักเรียน** → กรอกรหัสห้องเรียน → กด **ดูรายชื่อ**
2. เลือกชื่อของตัวเองจากรายชื่อที่ครูเพิ่มไว้ (ไม่ต้องสมัคร ไม่ต้องใช้รหัสผ่าน)
3. เปิดใบกิจกรรม อ่านคำสั่ง พิมพ์คำตอบหรือแนบไฟล์ แล้วกด **ส่งใบกิจกรรม**
4. ครูตรวจแล้วจะเห็นผล คะแนนรายหัวข้อ และความคิดเห็นในหน้านั้น

## ที่เก็บข้อมูล

- ฐานข้อมูล: `data/app.db` (SQLite)
- ไฟล์แนบ: `data/uploads/`

สำรองข้อมูลโดยคัดลอกโฟลเดอร์ `data/` ทั้งโฟลเดอร์ (แนะนำให้หยุดเซิร์ฟเวอร์ก่อน)

```bash
npm run reset    # ล้างข้อมูลทั้งหมด
npm run seed     # สร้างข้อมูลตัวอย่างใหม่
```

## การตั้งค่า

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
| --- | --- | --- |
| `PORT` | `3000` | พอร์ตเซิร์ฟเวอร์ |
| `HOST` | `0.0.0.0` | อินเทอร์เฟซที่รับการเชื่อมต่อ |
| `DATA_DIR` | `./data` | ตำแหน่งฐานข้อมูลและไฟล์แนบ |
| `CORS_ORIGINS` | `https://rachatasawasdikit-collab.github.io` | รายการ origin ที่อนุญาตให้เว็บภายนอกเรียก API คั่นด้วยจุลภาค เช่น `https://rachatasawasdikit-collab.github.io` |

ตัวอย่าง: `PORT=8080 npm start`

## โครงสร้างโปรเจกต์

```
server/
  index.js     Express API และการเสิร์ฟหน้าเว็บ
  db.js        สคีมา SQLite และตัวช่วย query
  auth.js      แฮชรหัสผ่าน session cookie และสิทธิ์
public/
  index.html   โครงหน้า SPA
  app.js       หน้าจอครู/นักเรียน
  styles.css   ธีมและเลย์เอาต์
scripts/
  seed.js      ข้อมูลตัวอย่าง
  reset.js     ล้างฐานข้อมูล
```

## หมายเหตุด้านความปลอดภัย

- ออกแบบสำหรับใช้ในวง LAN หรือเครื่องส่วนตัว รหัสผ่านถูกแฮชด้วย scrypt และ session เป็น cookie แบบ HttpOnly
- หากเปิดให้เข้าจากอินเทอร์เน็ต ควรใช้ HTTPS ผ่าน reverse proxy และเปลี่ยนรหัสผ่านตัวอย่างทั้งหมด
- ยังไม่มีระบบลืมรหัสผ่าน/รีเซ็ตรหัสผ่านผ่านอีเมล
